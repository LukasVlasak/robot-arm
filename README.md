# ADA526 Robot Arm

This repository contains the development of a robotic arm created as part of the **ADA526 – Applied Robot Prototyping** course at Western Norway University of Applied Sciences (HVL).

The goal of the project is to design, manufacture and program a functional robotic arm from scratch. The project combines mechanical design, 3D printing, robotics control and computer vision.

## Project

The development includes:

- design of the robot structure
- CAD modelling and mechanical design
- structural analysis and basic engineering calculations
- 3D printing and manufacturing
- Dynamixel servo motor integration
- robot control and trajectory generation
- development of the control software in Python
- ROS 2 integration
- Intel RealSense camera integration
- computer vision
- testing and evaluation

The robot is developed iteratively, with individual components being designed, analysed, manufactured and tested throughout the project. Mechanical design decisions are evaluated with respect to properties such as stiffness, strength, weight, geometry and expected loading.
